# 🎓 University Management System

## 📌 Project Description
The **University Management System** is a Java-based desktop application designed to streamline various college administrative processes. This project provides a structured system for handling student and teacher records, fees, attendance, examination results, and other administrative functionalities.

## 🚀 Technologies Used
- **Core Java**
- **MySQL**
- **Java Swing** (for UI design)

## 📂 Module Details
This project contains a **single module: Admin**, which includes functionalities for managing students, teachers, and user authentication.

## 📌 Features

### 🧑‍🎓 Student Management
- ➕ **Adding new students**
- 🔍 **Viewing student details**
- ✏️ **Updating student information** (address, phone number, email, course, branch)
- 💰 **Managing student fees**
  - Calculating and updating fee details
  - Recording fee payments
  - Viewing fee payment history
- 🏖️ **Leave Management**
  - Applying for leave
  - Monitoring leave requests
  - Viewing leave history
  - Searching leave requests by roll number
- 📝 **Examination Management**
  - Entering and managing examination results
  - Viewing examination results
  - Generating reports based on exam performance

### 👨‍🏫 Teacher Management
- ➕ **Adding new teachers**
- 🔍 **Viewing teacher details**
- ✏️ **Updating teacher information**
- 🏖️ **Leave Management**
  - Applying for leave
  - Recording leave requests
  - Viewing teacher leave history
  - Searching leave requests by employee ID

### 🔐 User Authentication
- 🔑 **Secure Login System**
  - Requires **username** and **password** authentication to ensure secure access.

## 📌 Use Cases
This system is intended to **simplify administrative tasks** and can be used by the **Admin** for:
- 🎯 **Student Management**
- 🎯 **Teacher Management**
- 🎯 **User Authentication**

### ✅ Student Management Use Cases
- **Registering new students** into the system
- **Accessing and modifying student details**
- **Managing student fee records**
- **Handling student leave applications**
- **Maintaining examination records and reports**

### ✅ Teacher Management Use Cases
- **Adding and updating teacher details**
- **Processing teacher leave applications**

### ✅ Authentication Use Cases
- **Ensuring secure system access through login authentication**

## 📌 How to Run the Project
1. **Clone the repository**
   ```sh
   git clone https://github.com/satish-pati/university-management-system
   ```
2. **Import the project into an IDE**
3. **Set up the database** using MySQL and import the required `.sql` file.
4. **Run the application** from your IDE.
